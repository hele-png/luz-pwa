# Luz · Asistente visual por voz (prototipo)

PWA en español para personas ciegas o con baja visión. Se usa con la voz: toca el botón grande, espera el tono y di
«describe lo que hay delante», «lee esto», «qué es esto», «llévame a la farmacia», «siguiente», «repite», «para» o «ayuda».

Las descripciones, lecturas y rutas son **simuladas** con textos de ejemplo. Sitio estático: `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icons/`.
